02ATP Board: a Jira replacement I built with AI

  • Athletic Training Portal
  • Built with Claude
  • Shared with the whole team

At ATP we needed real agile tracking (sprints, story points, priorities, owners) but didn't have the budget for paid project-management software. So I built our own. The ATP Board is a shared, live sprint board the whole team works out of, built with Claude.

  • Sprints with real tracking: start and complete sprints, see days left and points done, and roll unfinished work into the next sprint or backlog.
  • Tickets that carry context: status, priority, story points, topics, multiple assignees, plus linked GitHub branches and PRs.
  • Live for everyone: updates show up for the whole team instantly, with search, topic filters, "assigned to me," and keyboard shortcuts.
  • Connected to the codebase: one click opens the ATP Code Map, so tickets and code live side by side.

AI is most powerful when you use it to build the exact tool your team needs. Instead of paying for software we'd only half use, I built one that fits how we actually work, at no software cost.
