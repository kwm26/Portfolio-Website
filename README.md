# Kyle McCutchen — Portfolio Website

Live site: https://kwm26.github.io/Portfolio-Website/

Personal portfolio covering production and project management, product
design (Athletic Training Portal), game development, and audio design.

## Pages

- `index.html` — home: intro, the four practice areas, featured media, contact
- `production.html` — production, project management & marketing (Cosmic Labs, ATP Board, AI-built video blur tool)
- `front-end.html` — Athletic Training Portal product design case study
- `game-dev/index.html` — Duo Chrome, Snowventure, Minimal Shade
- `game-dev/audio.html` — Gravity SFX library and Unreal Engine audio demo

## Tech

Static HTML/CSS/JS — no build step, no framework. Open `index.html` in a
browser to preview, or serve the folder with any static file server.

- `css/style.css` — brutalist design system (bright blue `#2FB6FF` accent)
- `js/site.js` — small interactions (area tiles keep the last-hovered highlight)
- `assets/img`, `assets/video` — WebP images, MP4 + WebM video

## Deployment

Hosted on GitHub Pages from the `main` branch. Push to `main` to publish.
