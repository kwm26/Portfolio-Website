# Kyle McCutchen — Portfolio Website

Personal portfolio site: game development, front-end engineering, audio
design, and production/UX work.

Static HTML/CSS/JS — no build step, no framework. Open `index.html`
directly in a browser to preview locally, or serve the folder with any
static file server.

## Status

Design direction in progress — currently exploring a bold, brutalist-style
visual identity (bright blue accent). Site structure and pages are being
built out incrementally.

## Deployment

Intended for GitHub Pages once the design is finalized.
